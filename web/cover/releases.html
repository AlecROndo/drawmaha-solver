The catalogue is RELEASES in src/drawmaha_solver/minidrawmaha/answer/releases.py; each grade is read from the file and key it names (figures/rung3/answer_sheet.json, figures/rung4/). An export copies the grade into its manifest, and the tests hold the copy to the file.

A research project by Alec Ondo. A heads-up pot-limit Drawmaha solver, built one game at a time, each graded against a known answer. Python, NumPy and torch; training on Modal; the site on Vercel. The code, the graders and the data behind every figure are public.
