A research project · Deep CFR on mini-drawmaha

A solver for a poker game nobody has solved.

Drawmaha is a split-pot draw and Omaha hybrid. This solver is built one game at a time: four smaller games, each solved and graded against a known answer before the next is started.

Results

Four games solved, each graded by exploitability

Exploitability is what a best response wins per hand against the solver's average strategy. Zero is a Nash equilibrium. Every grader reads the game's rules and nothing from the solver it grades.

Method

Graded by an exact best response

Each game is solved, then a best response is computed exactly against the average strategy. What it wins per hand is the grade. A game is not called solved on a learning curve.

A grader shares no code with its solver

Every grader imports the game's rules and nothing else, so a bug cannot sit in both and cancel. Hidden cards are summed over before the responder takes a maximum.

Every figure is regenerated

Python, NumPy and torch; training runs on Modal and the site on Vercel. Every chart and table here is written from committed data by a named command, never edited by hand.

A research project by Alec Ondo. A heads-up pot-limit Drawmaha solver, built one game at a time, each graded against a known answer. Python, NumPy and torch; training on Modal; the site on Vercel. The code, the graders and the data behind every figure are public.
