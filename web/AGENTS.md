# `web/` — the site

`DESIGN.md` in this directory is the UI standard and it is enforced. Read it
before touching a stylesheet, a `<style>` block or a component's classes, and
afterwards run
`uv run pytest tests/test_ui_standard.py tests/test_shared_chrome.py tests/test_cover_page.py`.

## What is here

- `cover/` — five static pages served at the root. `index.html`,
  `rules.html`, `benchmarks.html` and `releases.html` are generated by
  `scripts/site/make_static_pages.py`: regenerated, never hand-edited.
  `cover.html` is the archived old front page, the one exception, edited by
  hand if at all. Beside them, `cover/fonts.css` (the `@font-face` rules
  for the files under `/fonts/`) and `cover/chip.js` (the plain-JS twin of
  `mark.ts`). `cover/README.md` says what each page reads and what the tests
  hold.
- `rung0-viz/`, `rung1-viz/`, `rung2-viz/`, `rung3-viz/`, `solver-viz/` —
  Vite + React + TypeScript apps. In each: `npm install`, `npm test`
  (vitest), `npm run dev`, `npm run build`.
- `hero-studies/` — a static share page and its clips at `/hero`, kept as it
  was.

| Route | Serves |
|---|---|
| `/` | `cover/index.html`, the homepage |
| `/rules` | `cover/rules.html` |
| `/benchmarks` | `cover/benchmarks.html` |
| `/releases` | `cover/releases.html` |
| `/research`, `/learn`, `/play` | `rung3-viz`, opening the Research, Learn or Play tab by path; `/rung3` serves the same app and picks the tab by hash |
| `/solver` | `solver-viz`, the range explorer |
| `/rung0`, `/rung1`, `/rung2` | the three benchmark apps (rock-paper-scissors, Kuhn, Leduc) |
| `/cover` | `cover/cover.html`, unlinked from the nav |
| `/hero` | `hero-studies/` |

`vercel.json` holds the rewrites; `scripts/site/serve_site.py` reads them
from there.

## Rules

- **Five files are byte-identical across the five apps**:
  `rung0-viz/src/theme.css`, `rung0-viz/src/main.tsx`,
  `rung0-viz/src/ui/site.tsx`, `rung0-viz/src/ui/site.test.tsx`,
  `rung0-viz/src/ui/mark.ts` and their copies. Edit rung 0's, `cp` it to the
  other four, `cmp` them; `tests/test_shared_chrome.py` fails otherwise.
  Per-app styling lives in that app's `src/index.css`, on top of the theme.
- **The static pages link the theme; they do not copy it.** The build
  serves rung 0's `theme.css` at `/theme.css`, and each page links it with
  `/fonts.css` and `/chip.js`. A chrome change lands in the theme (copied to
  the five apps) and reaches the pages through the link. The pages' top bar
  and footer are `site.tsx`'s markup written out as HTML by the generator,
  so a change to the nav or the footer is made in `site.tsx` and in
  `scripts/site/make_static_pages.py`, then the pages are regenerated.
- **No CFR in TypeScript.** The apps render solves exported from Python
  (`kuhn-analysis --json`, `leduc-analysis --json`, `minidraw-deals`,
  `minidraw-ranges`) or POST locked rows to a local Python exploit server.
  Only rules arithmetic is transcribed, and each app's `*.test.ts` pins it
  against the same tables the Python suite pins.
- **Adding a surface** touches `vercel.json` (a rewrite),
  `scripts/site/vercel_build.sh` (the `rungs` list for an app, the page loop
  for a static page), the `APPS` tuples in `tests/test_shared_chrome.py` and
  `tests/test_ui_standard.py` (or `PAGES` there and in
  `tests/test_cover_page.py` for a page), and, if the nav names it, `NAV`
  and the `Surface` type in `site.tsx` with `NAV` in the generator.
- **Colour is the series and action tokens.** A chart's lines and bars read
  `--series-1/2/3` (ink, accent, muted ink; a dash pattern for a fourth),
  and an action reads `--act-bet`, `--act-call` or `--act-check` (bet and
  raise in the accent, call green, check and fold blue). An app may name
  its own figure inks in its `:root`, each defined over the theme's tokens
  (rung 1's `--jack` / `--king` / `--queen`, rung 2's `--rank-*` ramp of
  ink, rung 3's `--rule-*` and `--obj-*`); the raw colours left in the app
  sheets are white and near-white card faces and rung 3's two lighter
  throw depths, the accent at 0.42 and 0.7 alpha. `--yellow` and `--pink` are
  retired: no sheet but the archived Cover names them, the theme included,
  and `test_retired_tokens_are_gone` holds it. The solver's mix bands read the triplet through `--rx-f`, `--rx-c`
  and `--rx-p` on `.rx` (the middle band is a check where the betting opens,
  `.rx[data-node='open']`), and `/rung3`'s Learn tab, which imports that
  view, inherits them; the trainer's coach bands use the action tokens
  directly. There is no separate fill pair to keep in step: `--call-fill`,
  `--pot-fill` and `--mix-*` are gone. In the chrome the accent is the
  focus ring and a checked radio, and prose links take it; the primary
  button, the current nav item and the current rail item are ink.
- **Where a number is illustrative rather than a solver's output, the page
  says so** where the number is drawn: in Full Drawmaha the solver's status
  line under the spot head, and "Policy: illustrative" in its "This spot"
  rows. Keep that sentence true when changing what is drawn.

## Checking them locally

The whole site as Vercel wires it: `bash scripts/site/vercel_build.sh`, then
`uv run python scripts/site/serve_site.py` (at `http://localhost:4321`). The
build runs five `npm ci` builds first; to look at the static pages alone,
mimic `public/` in a temp dir and serve it with `http.server`, as
`cover/README.md` lays out under "Checking them locally".
